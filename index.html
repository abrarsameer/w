Antiflood
CommandDescription
/floodView current antiflood settings
/setflood <number/off>Set max consecutive messages before action triggers
/setfloodtimer <count> <duration>Timed antiflood (e.g. 10 messages in 30s)
/floodmode <action>Action: ban / mute / kick / tban / tmute
/clearflood <yes/no>Delete messages that triggered flood

Examples

/setflood 7 → trigger after 7 messages /setflood off → disable antiflood /setfloodtimer 10 30s → trigger: 10 msgs in 30 seconds /setfloodtimer off → disable timed antiflood /floodmode mute → mute the flooder /floodmode tban 3d → 3-day temp ban

Pattern Modifiers

PatternMeaning
?Any single non-whitespace character
*Any number of non-whitespace characters
**Any number of characters including spaces
exact:wordOnly matches exact word, not "word here"
prefix:wordMatches messages starting with "word"
lookalike:wordMatches visually similar chars (e.g. Cyrillic)
file:*.zipMatch file extensions
inline:@gifMatch inline bot usage
forward:@channelMatch forwards from a channel

Override Tags (add to reason)

{ban} {mute 6h} {tmute 6h} {warn} {skick} {sban} → custom action {nodel} → prevent deletion for this trigger {del} → force deletion even if blocklistdelete is off Examples: /blocklistmode warn /addblocklist boo Don't scare the ghosts! {tmute 6h} /addblocklist "the admins suck" Respect your admins! /addblocklist (hi, hey, hello) Stop saying hello! /addblocklist "bit.ly/*" We dont like shorteners! /addblocklist "follow ** X" No promoting X accounts! /addblocklist "exact:hi" Only matches just 'hi' /addblocklist "lookalike:bot" Matches 'bot' + lookalikes /addblocklist "file:*.zip" zip files not allowed! /addblocklist "inline:@gif" gif bot not allowed! /addblocklist "forward:@botnews" channel not allowed!

Filter Special Tags

TagEffect
{admin}Only triggers for admins
{user}Only triggers for non-admins
{allow_bot}Allow other bots to trigger this filter
{protect}Reply cannot be forwarded/screenshotted
{replytag}Reply to the person being replied to, not sender
"exact:trigger"Trigger only if message is exactly this
"prefix:trigger"Trigger if message starts with this

Examples

/filter hello Hello there! How are you? /filter hello Hello {first}! How are you? /filter "hello friend" Hello back! Long time no see! /filter (hi, hey, hello, "hi there") Hello back! Random replies (use %%% separator): /filter hi Hello! %%% Hey there! %%% What's up? Force {user} filter as admin: trigger force Get unformatted: trigger noformat
